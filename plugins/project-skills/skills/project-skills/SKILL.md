# Skill: project-skills (em construção)

Este arquivo é um marcador. Ele existe para que o plugin `project-skills` seja um plugin
válido — com pasta de skills, entrada no catálogo e linha na receita do bootstrap — antes de
qualquer skill mudar de casa para dentro dele. Ninguém edita este arquivo: ele será
substituído pelas skills reais quando elas se mudarem, cada uma no seu próprio passo.
